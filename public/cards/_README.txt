One folder per template: public/cards/<template-id>/
Template ids: lowercase letters, numbers and dashes only (example: wedding-floral-1).
Put the background PNG in the folder and name it starting with "bg" (example: bg.png).
Every other PNG/WebP/SVG in the folder becomes a layer.
Open /dev/card-lab?t=<template-id> to place the layers and save spec.json.
